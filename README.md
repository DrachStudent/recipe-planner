# Довідник рецептів із планувальником меню

Настільний застосунок для обліку рецептів, інгредієнтів, диференційованого розрахунку калорійності страв і формування тижневого меню зі списком покупок.

## Технології
- **Java 25** (OpenJDK 25.0.2), модульна система JPMS (`module-info.java`)
- **JavaFX 25** (FXML, `TableView`, `FilteredList`, `SortedList`, `javafx.concurrent.Task`)
- **Jackson** (`jackson-databind`) — поліморфна серіалізація та десеріалізація JSON
- **JAXB** (`jakarta.xml.bind`) — експорт тижневого списку покупок у XML
- **Apache Maven** — збирання та керування залежностями
- **java.util.logging** — журналювання подій і помилок у `logs/recipe_planner.log`

## Основні можливості
- Ієрархія класів моделі: інтерфейс `Nutritional`, абстрактний клас `Recipe` і підкласи `MainDish` (ккал/порція), `Dessert` (ккал/100 г), `Drink` (ккал/100 мл).
- CRUD-операції для рецептів, інгредієнтів і записів тижневого меню з валідацією введення та захистом посилальної цілісності.
- Миттєвий пошук за назвою рецепта та інгредієнтом, фільтрація за категорією, сортування за часом приготування та калорійністю.
- Імпорт і експорт довідника в JSON (із записом через тимчасовий файл), експорт списку покупок у XML.
- Багатопотоковий імпорт набору з 15 000 рецептів, пакетний розрахунок калорійності (`ExecutorService`, `ConcurrentHashMap`, `AtomicInteger`) із порівнянням `T₁` та `Tₙ` і фонова агрегація списку покупок.
